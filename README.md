# Tradução PT-BR — The Walking Dead Universe RPG (Foundry VTT)

Módulo não oficial de tradução da interface do sistema **The Walking Dead Universe RPG (`twdu`)** para Português (Brasil) no Foundry VTT.

## O que este módulo traduz
* Fichas de Personagem Jogador, PNJ, Refúgio, Desafio e Animal
* Atributos, perícias, níveis de dano, estresse e rolagem de dados (Year Zero Engine)
* Menus do sistema, controles de Nível de Ameaça e mensagens de chat

> **Nota:** Este módulo traduz apenas a interface do sistema. Conteúdos de compêndios (descrições de talentos, armas e equipamentos) não são alterados.

## Como instalar no Foundry VTT

1. Abra o Foundry VTT e vá até a tela inicial de configuração (**Setup**).
2. Acesse a aba **Add-on Modules** e clique em **Install Module**.
3. No campo **Manifest URL** (na parte inferior da janela), cole o link abaixo:
   ```text
   [https://raw.githubusercontent.com/GabriellSilveira/twdu-ptbr/main/module.json](https://raw.githubusercontent.com/GabriellSilveira/twdu-ptbr/main/module.json)
